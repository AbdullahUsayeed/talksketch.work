Get started

Start in three minutes.

TalkSketch listens to whatever plays on your laptop, writes structured notes, and fills a local board — no bot joins the call and there is no meeting link to paste.

01

Install

The quickest route is winget — no browser download warning:

Or in PowerShell — downloads, verifies the checksum and installs without the SmartScreen prompt:

Or download the installer and run it. SmartScreen will warn because the preview is not code-signed yet: More info → Run anyway. It installs per user, no admin required.

02

Sign in

Open TalkSketch and choose Sign in with Google. Your browser opens, you approve, and the app starts a 3-day trial. No card required.

Pilot keys still work for self-hosted installs.

03

Run anything

Play the meeting in any app, press Start notes, allow screen/audio sharing and tick Share system audio. Chunks are cut at pauses, notes update about once a minute, and Stop writes the final notes.

If the installer will not run

Windows trusts this preview less than it trusts a signed app. Try these in order.

  1. Install with winget. winget install --id TalkSketch.TalkSketch -e fetches the same build without the browser download warning.
  2. “Windows protected your PC”. Click More info, then Run anyway. The Run button only appears after that panel expands.
  3. Double-clicking does nothing. The file is blocked by the download mark. In PowerShell, from your Downloads folder, run Unblock-File .\TalkSketch-Setup.exe, then start it again.
  4. Smart App Control blocked it. Windows 11 with Smart App Control turned on refuses unsigned apps with no bypass. It lives under Windows Security → App & browser control; turning it off is permanent unless Windows is reset, so only do that if you understand the trade-off.

Still stuck? Send the output of winget install --id TalkSketch.TalkSketch -e --verbose-logs to hello@talksketch.work.

What you need

  • Windows 10 or 11, x64.
  • Any app with audio: Meet, Zoom, Teams, WhatsApp, a YouTube lecture.
  • A Google account for the 3-day trial.
  • Consent from participants: tell them an AI assistant is taking notes.

What is still beta

  • Audio capture uses the OS share picker: pick the window and enable system audio.
  • Transcription is cloud-based (language auto-detected); accuracy varies with accents and crosstalk.
  • Unclear names, numbers or gaps are flagged for you to verify instead of guessed.
  • No bot joins the call. Audio is transcribed, not stored; sessions stay on your disk.
