Pilot

Start in three minutes.

The desktop preview joins Google Meet in its own window, reads the captions, and writes live notes, action items and a whiteboard next to the call.

01

Install

Download the Windows installer, run it, and launch TalkSketch. SmartScreen will warn because the preview is not code-signed yet: More info → Run anyway. It installs per user, no admin required.

Download for Windows
02

Get a key

Pilot seats are issued manually so we can keep the model costs under control. Email us and we will send a key tied to your account.

Request a pilot key

Public demo key: TALKSKETCH (rate-limited, shared).

03

Run a meeting

Open the app, paste your Meet link, join, turn on captions (CC), then press Start notes. Notes, actions and the board update in the right panel. Stop at the end to write the summary.

What you need

  • Windows 10 or 11, x64.
  • A Google Meet call. Captions must be available and enabled.
  • Your pilot access key.
  • Consent from participants: tell them an AI assistant is taking notes.

What is still beta

  • Audio capture uses the OS share picker: pick the meeting window and enable system audio.
  • Transcription is cloud-based (language auto-detected); accuracy varies with accents and crosstalk.
  • No bot joins the call. Audio is transcribed, not stored.
